# Quickstart — gregMod.MoreSpools

> gregMod.MoreSpools** adds configurable long cable spools to the Data Center shop without requiring a recompile for configuration changes.

Repo: [https://github.com/mleem97/gregMod.MoreSpools](https://github.com/mleem97/gregMod.MoreSpools) · Version: `0.1.0` · License: Apache-2.0.

## 1. Clone

```bash
git clone git@github.com:mleem97/gregMod.MoreSpools.git
cd gregMod.MoreSpools
```

## 2. Build / Run

Choose **one** path depending on the tech stack:

```bash
# .NET
dotnet build -c Release
dotnet run --project src/

# Node / pnpm
pnpm install
pnpm build
pnpm start

# Python
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m <modul>
```

## 3. Test

```bash
dotnet test            # .NET
pnpm test              # Node
pytest                 # Python
```
